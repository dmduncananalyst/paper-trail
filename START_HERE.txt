BEFORE PUBLIC DEPLOYMENT
1. Choose the real public website domain. Current canonical and sitemap URLs use
   the private Paper Trail preview origin.
2. From the extracted folder, run the following with your real HTTPS domain:
   python3 tools/configure-domain.py https://your-actual-domain.com
   This changes URLs in every HTML file, robots.txt and sitemap.xml.
3. Publish the HTML pages, assets, robots.txt and sitemap.xml at the public root.
   Ensure pages return HTTP 200 without a login requirement or an X-Robots-Tag
   noindex header. Use one canonical HTTPS domain and redirect duplicate hosts.
4. Add and verify that domain in Google Search Console. Submit /sitemap.xml and
   review page indexing and URL inspection results. This submission is not done
   by downloading this ZIP.

INDEXING AND LINKS
A private preview cannot be indexed publicly. The public files permit indexing,
but Google decides which pages to crawl and index. A sitemap is a discovery aid.
Internal links are included. External backlinks are links from other websites,
so they cannot be created simply by adding code to these files. Use accurate
business listings and legitimate editorial or partner mentions when appropriate.
Do not create fake offices or purchase links intended to manipulate rankings.

CONVERSATIONS
Open index.html to review the layout and guided conversation. Once published on
an HTTPS website, this download sends reviewed notes directly to the supplied
HubSpot form. Name, email, phone, company name and the combined message are
required. All conversation answers are included in the message. Field names were
verified against the published form. Payloads and errors were tested with mocked
responses, without sending a synthetic inquiry to your live account.
The hosted Site also stores an inquiry copy in its private inbox. This frontend
download does not include that private inbox, server source or account credentials.
Live generative model answers remain unconnected. Referenced published answers
and guided prompts are available. Local previews never claim a note was sent.
