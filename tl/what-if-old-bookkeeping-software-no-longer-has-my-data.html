Muling Buuin ang mga Rekord Kapag Hindi Magagamit ang Lumang Data ng Software

Kung hindi na nagbibigay ng datos ang iyong lumang sistema ng bookkeeping, magsimula sa pamamagitan ng pagsuri sa mga backup, pag-export, at mga opsyon sa pag-access bago muling buuin ang anuman. Ang kawalan ng access sa software ay hindi nangangahulugang wala na ang lahat ng rekord. Ang mga bangko, vendor, customer, at mga sistema ng pagbabayad ay maaari pa ring magtago ng mga bahagi ng kasaysayan ng transaksyon.

Imbentaryo kung ano pa ang maaari pang mabawi

Maghanap ng mga naka-save na ulat sa pananalapi, mga pag-export ng general ledger, mga ulat ng rekonsiliasyon, mga invoice at mga file ng pahayag. Tanungin ang dating provider o awtorisadong may-ari ng account tungkol sa pag-access sa archival at availability ng backup. Itala kung aling mga panahon ang sakop at kung saan nananatili ang mga puwang. Ang isang folder ng mga pahayag ng bangko ay kapaki-pakinabang, ngunit hindi nito kinakailangang ipapakita ang mga aplikasyon ng invoice, layunin ng negosyo o mga entry sa accounting na hindi cash.

Buuin muli mula sa mga independiyenteng talaan

Gumamit ng mga statement ng bangko at card kasama ng mga invoice, resibo, statement ng nagpapautang, at detalye ng processor. Bumuo mula sa huling maaasahang balanse at i-reconcile ang bawat apektadong panahon nang sunod-sunod. Iwasang ituring ang bawat deposito bilang isang benta o bawat withdrawal bilang isang gastos. Itala ang pinagmulan ng bawat muling itinayong item at magpanatili ng listahan ng anumang bagay na nananatiling hindi tiyak.

Protektahan ang nabawing kasaysayan

I-save ang mga accessible export bilang karagdagan sa anumang naibalik na software file. Panatilihin ang mga dokumentong sumusuporta sa mga tax return at mga ulat sa pananalapi sa ilalim ng naaangkop na mga kinakailangan sa pagtatala. Kung ang mga nakaraang return ay batay sa mga rekord na hindi na mababawi o ngayon ay tila hindi tumpak, talakayin ang isyu sa tagapaghanda ng buwis. Dapat ipakita ng plano ng pagkukumpuni ang magagamit na ebidensya at saklaw ng mga kakulangan, sa halip na mangako ng isang kumpletong rekonstruksyon bago suriin kung ano ang natitira.
